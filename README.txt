MEU FINANCEIRO - APP PARA IPHONE (PWA)

1. Extraia o ZIP.
2. Publique o conteúdo desta pasta em hospedagem HTTPS (ex.: GitHub Pages, Netlify ou Cloudflare Pages).
3. No iPhone, abra a URL publicada no Safari.
4. Toque Compartilhar > Adicionar à Tela de Início > Abrir como App da Web > Adicionar.
5. Abra o ícone Meu Financeiro na tela inicial. Após a primeira abertura, os arquivos básicos poderão funcionar offline.

IMPORTANTE:
- Não basta abrir index.html pelo aplicativo Arquivos para instalar como PWA; é necessário um endereço HTTPS.
- Os dados ficam no armazenamento local do navegador/app, não sincronizados. Faça backups regulares pelo próprio app.
- Dados da versão HTML no computador não migram automaticamente para a URL nova; exporte um backup na versão anterior e importe na nova.
- Não envie seus arquivos de backup financeiro a um repositório público.
- Isto não é um app nativo IPA. Para gerar um IPA é necessário um ambiente macOS/Xcode (local ou nuvem) e configuração de assinatura Apple.
